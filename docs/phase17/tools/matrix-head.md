## 3. منهجية الحكم لكل شاشة
**ناجح** = 0 مخالفات axe بالعربية والإنجليزية + RTL في العربية وLTR في الإنجليزية مطبقة فعلاً + تركيز لوحة المفاتيح ظاهر + لا تمرير أفقي على أي عرض + لا أهداف صغيرة (عدا علامات الخريطة SVG، استثناء «المكافئ» في WCAG 2.5.8) + لا خطأ نقر غير مفحوص + لا رمز خام.

«نُقرت/اكتُشفت»: الفرق بين الرقمين عناصر معطلة بحق (مثل «الصفحة التالية» في قائمة من صفحة واحدة) أو تجاوزت الحد الأقصى أو مستثناة عمداً (تسجيل الخروج، إعادة ضبط البيانات، الروابط الخارجية).
