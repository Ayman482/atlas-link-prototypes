# سجل العيوب والإصلاحات — Phase 17

**القاعدة:** كل بند «مُصلح» أُعيد اختباره بعد الإصلاح، ودليل التحقق مذكور. العيوب **المتحقق منها** منفصلة عن **المخاطر المحتملة** وعن **غير المختبر**.
**مقياس الخطورة:** حرجة (تمنع العمل أو تسرب بيانات) · عالية (خطر أمان/سلامة أو مسار إلزامي معطوب) · متوسطة (سلوك خاطئ له حل بديل) · منخفضة (تجميلية/لغوية/تجربة).
