## 2. فصل العرض عن الإنتاج

### 2.1 آلية الفصل (وقت البناء، لا وقت التشغيل)
| الطبقة | المفتاح | السلوك في الإنتاج |
|---|---|---|
| الويب (Next.js) | `NEXT_PUBLIC_MEDLOG_MODE=production` | `IS_DEMO=false` يُثبَّت في الحزمة؛ لا يُنشأ المحرك المحلي (`LocalTransport`) أبداً؛ `demoLogin()` يرمي `FORBIDDEN`؛ يلزم `NEXT_PUBLIC_API_BASE`؛ لا قوائم حسابات، لا رمز MFA تجريبي، لا شارة «بيانات عرض» |

| الخادم | `NODE_ENV=production` | يرفض البدء دون `MEDLOG_SECRET` (≥ 32 حرفاً) و`CORS_ORIGIN` صريح؛ كل مسارات `/auth/*` عدا الخروج تعيد 501 `AUTH_PROVIDER_NOT_CONFIGURED`؛ `demo-login` معطّل؛ إعادة الضبط غير متاحة؛ الأصل المحلي غير مسموح |
