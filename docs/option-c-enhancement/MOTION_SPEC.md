# مواصفة الحركة — الخيار C (Emerald Health)

> المصدر الوحيد للقيم: `packages/tokens/tokens.json` ← يولّد `tokens.css` للويب و`tokens.dart` لتطبيقات Flutter.
> الويب: **Motion for React** (`motion@14.2.0`، من `motion/react`) — Flutter: الرسوم المتحركة الأصلية (`AnimatedContainer`، `AnimatedSwitcher`، `TweenAnimationBuilder`، `AnimationController`).

## 1. المبادئ

1. **الحركة تشرح، لا تزيّن.** كل حركة يجب أن تجيب عن سؤال: ماذا تغيّر؟ من أين جاء؟ أين ذهب؟ هل نجح الإجراء؟
2. **التنبيهات الحرجة لا تنتظر الحركة.** شريط الانحراف الحراري (`CriticalBar`)، بطاقات المؤشرات الحرجة، وشارة «حرج» تظهر فوراً دون أي تأخير دخول أو تتابع (stagger). لا يُخفى أي تنبيه حرج خلف درج أو قائمة أو رسم متحرك.
3. **لا حركة وهمية للمواقع.** لا تُحرّك نقاط الخريطة على المسار كأنها تتبع حي. النقطة تُرسم في آخر موقع مؤكد فقط، والخط بين المدينتين هو «المسار المخطط». النبض (`pulse`) مسموح فقط على المؤشر «مباشر» ذي البيانات الحديثة فعلاً، ويتوقف مع تقليل الحركة.
4. **احترام «تقليل الحركة».** الويب: `MotionConfig reducedMotion="user"` على مستوى الجذر يلغي الإزاحة والتحجيم ويُبقي تغيّر الشفافية فقط. Flutter: `Motion.reduced(context)` يقرأ `MediaQuery.disableAnimations` ويعيد مدة صفرية.
5. **الأداء 60 إطاراً/ث.** تُحرَّك فقط الخصائص المركّبة (`transform`، `opacity`). لا تحريك لـ `width/height/top/left` باستثناء `Collapse` (ارتفاع تلقائي قصير ≤ 220ms ومحصور في عنصر واحد).

## 2. رموز المدة

| الرمز | المدة | الاستخدام |
|---|---|---|
| `instant` | 120ms | تغيّر لون الحالة، hover، ضغط زر |
| `fast` | 160ms | ظهور التلميحات، الستارة (scrim)، تبديل التبويب |
| `base` | 220ms | انتقال الصفحة، دخول البطاقات، فتح الأكورديون/الصف الموسّع، إعادة ترتيب التوقفات |
| `slow` | 300ms | الأدراج الجانبية، النوافذ الحوارية، رسم علامة النجاح |
| `emphasis` | 420ms | تأكيد النجاح فقط (الرمز متاح؛ علامة ✓ في الويب نابض ربيعي ≈ 400ms) (علامة ✓ الربيعية) — لا يُستخدم لأي شيء يحجب العمل |
| `stagger` | 40ms | الفارق بين العناصر المتتابعة؛ الحد الأقصى للتأخير التراكمي 240ms |

نطاق التفاعلات الصغيرة الإلزامي **150–300ms** مُلتزم به؛ 120ms لتغيّرات اللون فقط، و420ms للتأكيد فقط.

## 3. منحنيات التسارع

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `standard` | `cubic-bezier(0.2, 0, 0, 1)` | الافتراضي لكل التغيرات داخل الصفحة |
| `decelerate` | `cubic-bezier(0, 0, 0, 1)` | العناصر الداخلة إلى الشاشة |
| `accelerate` | `cubic-bezier(0.3, 0, 1, 1)` | العناصر الخارجة |
| `emphasized` | `cubic-bezier(0.2, 0.9, 0.3, 1)` | الأدراج والنوافذ |

## 5. ممنوعات

- تحريك المواقع على الخريطة بين نقطتين لإيهام التتبع الحي.
- تأخير ظهور أي شارة «حرج» أو شريط تنبيه أو زر «إقرار».
- حركات تلقائية متكررة بلا معنى (تم حذف الـ sparklines الزخرفية وتأثيرات «flows» على الخريطة).
- حركة تمنع التفاعل: كل الحركات قابلة للمقاطعة، والأزرار تبقى قابلة للنقر أثناءها.
- استخدام مدة > 300ms لأي شيء يقف بين المستخدم وإجراء تشغيلي.
